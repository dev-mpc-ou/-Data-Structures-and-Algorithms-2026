# Bộ ôn thi giữa kỳ - Cấu trúc dữ liệu và giải thuật

Bộ gồm 3 đề mô phỏng:

1. Mảng + các thuật toán sắp xếp / tìm kiếm.
2. Linked List + quản lý sinh viên + file.
3. BST + duyệt cây + Hash + vòng tròn + anagram.

Mỗi thư mục có:
- File `.md`: đề và checklist ôn tập.
- File `.cpp`: chương trình mẫu có menu.
- File `.txt`: dữ liệu để đọc nhanh.

## Cách luyện hiệu quả

### Vòng 1
Chạy `.cpp` với file `.txt`.

### Vòng 2
Tự viết lại từng hàm quan trọng:
- insert / delete
- search
- sort
- traversal
- file I/O
- hash collision

### Vòng 3
Chỉ mở `.md`, không nhìn code và tự làm.

### Vòng 4
Đổi dữ liệu và tự nghĩ thêm biến thể.

## Lưu ý

Bộ này là đề luyện tổng hợp được xây dựng từ đề cương bạn cung cấp. Nó không phải đề thi chính thức và không khẳng định trùng đề thật.
